Everything you need to know about your batteries

📊 Real raw FCC health

Reads the gas-gauge IC directly. Same numbers Apple's own diagnostics use, exposed transparently.

🔄 Cycle counting & forecast

Linear-regression forecast tells you when health will hit 80% and how many cycles you have left.

📱 iPhone & iPad support

Full battery details over USB or Wi-Fi via libimobiledevice. Cycle count, capacity, temperature, voltage.

⚡ Power adapter classifier

Identifies Apple original vs MFi-certified vs generic chargers from the FamilyCode IORegistry value.

📈 History & charts

SQLite-backed history with overlapping charts across all your devices. Export to CSV.

🔔 Smart notifications

Anomaly detection: alerts you if health drops faster than normal. Plus low battery, hot battery, calibration reminders.

🌐 Localized

Italian and English out of the box. More languages welcome via PR.

🔒 Privacy first

No analytics, no network calls, no account. Your data is in ~/Library/Application Support/BatteryMonitor.

First launch

The app is signed ad-hoc, so Gatekeeper warns on first launch. Right-click the .app → Open → confirm. macOS remembers the choice.

iOS / iPad support

Install libimobiledevice:

brew install libimobiledevice usbmuxd

Connect the device, unlock it, accept "Trust this Mac". Wi-Fi works after a one-time USB pairing.

Build from source

git clone https://github.com/Gianmarco0001/Doctor-Battery.git
cd Doctor-Battery
./build.sh
open build/BatteryMonitor.app

Pure Swift + SwiftUI + Swift Charts. No third-party dependencies. ~1300 LOC.
